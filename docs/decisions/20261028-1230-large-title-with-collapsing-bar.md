# 文章开头用大标题，吸顶改为滚出后才出现的固定小标题栏

## 触发
评审时指出标题（19px 无衬线）比正文（18px 衬线）还不显眼。用户回应："吸顶时候能一致。你有什么办法"，随后选定方案 B："按照b来操作，web和mobile都做好e2e检测，没问题了就直接上线"。

## 决定
首页每篇文章开头放 28px（手机 24px）大标题和日期。吸顶栏拆成独立的 52px 小标题栏，装在高度为 0 的 sticky 容器里，大标题滚出顶部后淡入，所有文章样式一致。文章页同样放大标题和日期，工具栏标题在大标题滚出后才显示，没有 JavaScript 时一直显示。

## 放弃的备选
- 标题保持小号、吸顶不变：层级弱，问题没解决。
- 同一个标题吸顶时缩小：标题块高度会从约 70px 变成 52px，吸顶瞬间正文向上跳约 18px，会破坏阅读位置的稳定。

## 后果
- 首页和文章页各多一个重复的标题节点；吸顶栏对读屏隐藏，大标题才是标题。
- 小标题栏单行显示，超长标题会被省略号截断。
- 文章页工具栏标题（含文章切换器）在页面顶部不可见，滚动后才出现。
