## Guestbook and article comments — 2026-11-10
One component renders both threads when `site.guestbook.url` is set: the about page ends with the guestbook (`#guestbook`, page `/about/`), and every article page has a comment thread (`#comments`, page `/writing/<slug>/`) after the article element, below related reading. Every sidebar's primary nav links to `/about/#guestbook` as 「留言板」. Each section ships `hidden`; JavaScript initialization reveals it immediately and handles the thread hash, then reads up to 100 visible comments for its page, newest first, from Supabase REST with the publishable key. Without JavaScript the section stays hidden. Failed loads show a message and a manual retry button instead of removing the destination. Reads and writes time out after 12 seconds; failed sends preserve the draft and do not automatically retry. Decision: docs/decisions/20261113-0154-comment-loading-failure.md. Posting calls `post_comment(page, name, content)` (`supabase/comments.sql`), which validates the page pattern and lengths, applies per-IP (salted hash, 5 per 10 minutes across the site) and site-wide (20 per minute) limits, and returns the row that the page prepends; its error names map to Chinese messages in `app.js`. Comments render with textContent. The composer copies values measured from claude.ai/new: 20px radius, a 1px rgba(0,0,0,.12) ring plus a 0 4px 20px rgba(0,0,0,.075) shadow, 14px inset on every side, 12px between the text and the bottom bar, 15px/20px text with 6px top and left padding growing to 240px, and a 28px send button with 8px radius in `--link` (Claude's #c6613f) flush with the bottom-right inset; the bar also holds the optional name field and status text, and the button is dimmed and disabled while the text is empty; Enter sends and Shift+Enter breaks lines except on touch devices. On mobile, the sidebar guestbook link closes the drawer. Decisions: docs/decisions/20261110-1600-supabase-guestbook.md, docs/decisions/20261110-1620-article-comments-composer.md, docs/decisions/20261110-1650-composer-measured-from-claude.md.

## Site analytics and footer visit count — 2026-11-10
`site.analytics` in `scripts/templates.mjs` holds a GoatCounter site code and a Cloudflare Web Analytics token; an empty value omits that service. With a GoatCounter code, every page loads the self-hosted `/assets/goatcounter-count.js` (async), a verbatim copy of GoatCounter's `public/count.js` at commit 478f026, because `gc.zgo.at` timed out from a network in China while `CODE.goatcounter.com` answered (refresh the copy and its `?v=` by hand when upgrading), and the footer carries a hidden `.visit-count` span. `app.js` fetches `https://CODE.goatcounter.com/counter/TOTAL.json`, keeps the digits of `count` and shows 「 · N visits」 (en-US digits, 「visit」 for 1) after 「© YEAR Henry Mei · All rights reserved」, where the name links to github.com/henrymeihao. N is GoatCounter's site-wide visits, not raw pageviews: its public counter only exposes visits, and raw pageviews need an API key that cannot be published; on any failure or a zero count the span stays hidden. Only the site-wide total is displayed; GoatCounter's dashboard still records per-page data. With a Cloudflare token, every page loads `https://static.cloudflareinsights.com/beacon.min.js` (defer); its data is only visible in the Cloudflare dashboard. Decisions: docs/decisions/20261110-1158-goatcounter-cloudflare-analytics.md, docs/decisions/20261110-1240-self-host-goatcounter-script.md, docs/decisions/20261110-1520-footer-visits-format.md.

## Sidebar category folders — 2026-11-10
The sidebar article directory is split into six collapsible folders, in this order: 实践, 行业, 工作, 社会, 生活, 文化.
