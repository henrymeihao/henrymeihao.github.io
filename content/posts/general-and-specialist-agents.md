我最近老在想一个问题：通用 Agent 到底会吃掉多少专业 Agent？

拿 Codex 这类产品来说，表面上它是写代码的。真正让我在意的是，它开始替人操作电脑了。

白领每天干的事，其实很少离开屏幕：搜资料、读文档、改表格、跑代码、发消息、做一版报告。以前 AI 只是帮你写两段话。现在你可以把一个目标交出去，再看它自己开网页、读文件、写代码、改东西。

这会先影响那些看起来很“专业”，但其实只是给模型套了一层流程的产品。

过去模型不够聪明，做一个金融 Agent，往往要接知识库、配工具、把步骤拆得很细。先读财报，再查新闻，再做估值，最后生成摘要。模型稍微走偏一点，就得加一层规则把它拉回来。这些东西就是常说的 harness。

模型再往前走，一部分 harness 会失效。不是因为产品团队没做价值，而是模型自己已经能把这几步串起来。

如果一个金融 Agent 只会读财报、搜新闻、写投资摘要，通用 Agent 迟早也会做。研究 Agent 也是，检索论文、归纳观点、写初稿，这些事很可能先被吞掉。

我不觉得专业 Agent 都会死。

一个真正能在金融机构里用的产品，要接机构数据、交易和风控系统，还要满足合规要求。它出错了，不能只说“模型幻觉了”。医疗、法律也是同样的道理。这里真正难的不是给模型一个 prompt，而是把它放进一套能承担责任的系统里。

所以我现在的判断是：通用 Agent 会先吃掉一批“领域包装很厚，实际工作很浅”的专业 Agent。

研究、办公、代码、内容生产会先被影响。它们的共同点是，大部分步骤都在电脑里完成，也比较容易检查结果。越是靠人手在几个软件之间搬运信息的工作，越容易被接过去。

但有些专用产品不会这么快消失。它们有独家的数据，有很深的系统集成，或者出了问题真的要有人负责。用户付费买的是一件事被稳定办成，不是某个模型跑分更高。

我还没想透的是：如果通用 Agent 最后能操作你所有的软件，它会不会变成新的操作系统？

到那时，我们可能不再先打开 Excel、飞书或金融终端，而是先说一句“把这事办了”。软件还在，只是退到后面去了。

Codex 这类产品离这一步还有距离。但入口确实在往 Agent 那边挪。
