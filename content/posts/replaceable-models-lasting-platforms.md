以后，模型大概率会越来越容易换。

改一封邮件，用便宜模型；做复杂分析，调用最强模型；碰到敏感数据，切到本地模型。一个 Agent 可以在后台自动路由，大多数用户甚至不必知道底下是哪家。

这意味着，只靠“模型领先”很难永久拿走超额利润。贵了、慢了、效果被追上了，应用方就有理由切换。

## **但模型能换，不等于 Agent 也能换。**

真正决定用户会不会留下来的，是它能不能把事情办成一个闭环。

想象你让 Agent 安排一次出差。它不仅要理解“下周去上海见客户”这句话，还得知道你的日程、常坐航班、公司差旅规则、哪些联系人是客户、什么金额需要审批；然后能查信息、订票、发通知，遇到失败还能回退或把问题交给你。

这不是换一个模型 API 就能补齐的。

它需要长期积累的上下文、可靠的数据连接、权限体系和一整套能把任务执行到底的产品能力。<strong>模型负责思考，平台决定它能否真正行动。</strong>

这也是腾讯、Google 这类公司仍可能在 AI 下半场占优势的原因。

腾讯的机会，不只是微信是一个大入口。更重要的是，用户已经在微信里聊天、联系服务、支付；企业在企微里协作、沉淀客户关系和业务流程。这些应用每天都在产生上下文。只要用户愿意授权，Agent 不必从零认识一个人，也不必要求用户再下载一个 App、迁移一套数据、学习一套新操作。

Google 也是同样的逻辑。搜索、Chrome、Android、Gmail、YouTube 和 Workspace，不是几个孤立产品，而是一张覆盖工作与生活的使用网络。AI 的价值不只在于回答得更聪明，而在于它能否基于这些已有场景理解意图，并把下一步执行下去。

<strong>当然，拥有数据不自动等于赢。</strong>用户会不会授权，隐私边界怎么设，权限能否被清楚地控制，任务出错后谁来兜底，都会决定这种优势能否兑现。

## **模型层和应用层，打的其实不是同一场仗。**

模型层比的是能力上限、推理成本、迭代速度和开发者生态。谁能用更低的成本把模型做得更聪明、更稳定，谁就更容易成为底层供给。但这里的领先很脆弱：一项能力被追上，价格被打下来，客户就可能把调用量切走。

应用层比的则是另一件事：谁拥有用户正在使用的场景，谁能接入足够的上下文和工具，谁能把一次次任务做成并留下来。它的护城河不只是模型效果，而是数据连接、流程设计、信任与习惯。用户换一个聊天机器人不难；换掉已经连着日程、文档、客户、支付和审批流程的工作方式，要难得多。

两层当然会互相挤压。模型公司会向上做 Agent 和入口，应用公司也会向下训练、部署自己的模型。但它们面对的核心约束不同：模型公司要持续证明“我仍然最强或最划算”；应用公司要持续证明“把事交给我，真的能办成”。

模型公司也不会坐着等。它们可以更早拿到强模型，更快做出好用的 Agent，也会努力把模型、工具和自己的生态绑在一起。

但我更在意的，已经不是“哪家的模型会永远第一”。这个答案变化太快了。

AI 下半场真正的竞争，是谁能先让用户养成一个习惯：遇到事情，不只是问 AI 一个答案，而是放心把目标交给它，并拿到结果。

模型会越来越像可替换的能力层。真正稀缺的，是用户数据、应用生态、可信权限，以及把一件事稳定办成的闭环能力。

谁把上一个时代积累下来的这些东西接进 AI，谁就更可能留住用户。
